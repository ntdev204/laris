# Extraction table and synthesis

## Extraction table columns
| Key | Problem | Model/assumptions | Method | Validation (sim/HIL/real; scenario) | Main results | Limitations (stated / observed) | Source reliability | Access (full/abstract) |

Guidance:
- Assumptions: small-angle, constant speed, no tire slip, known parameters, linearization point, sampling period.
- Results: report numbers only as stated in the paper, with units and conditions; never estimate.
- Limitations: separate the authors' stated limitations from those you observe.
- Source reliability: peer-reviewed journal / conference / preprint / thesis; validation strength; code available.

## Thematic synthesis
For each theme:
1. What most works agree on (consensus) and the evidence strength.
2. Where results contradict, and plausible reasons (different models, assumptions, metrics).
3. Trends over time.
4. What is missing (candidate gaps, passed to research-gap with confidence levels).

## Quality appraisal (per theme)
- Strong: multiple independent works, real-vehicle or HIL validation, reproducible.
- Moderate: simulation-only but consistent across works.
- Weak: single source, unclear setup, preprint only.

## Coverage-limits statement (always include)
Sources searched, date of last search, inaccessible databases, languages, known blind spots.
