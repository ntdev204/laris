# Pre-submission integrity checklist

Mark each item: PASS / FIX / UNKNOWN (with note).

## Originality and reuse
- [ ] No text copied from others without quotation and citation.
- [ ] Overlap with own prior work (conference version, thesis, preprint) disclosed and cited per venue policy.
- [ ] Extended versions add substantial new content as the venue requires (verify the venue's rule).
- [ ] No concurrent submission of the same work.

## Authorship
- [ ] All authors meet the venue's authorship criteria; no gift or ghost authorship.
- [ ] Contribution statement matches actual roles; order agreed by all authors.
- [ ] All authors approved the submission.

## Data, code, figures
- [ ] Data and code availability statement accurate (where, license, restrictions).
- [ ] Figures not manipulated beyond uniform adjustments; no selective cropping that changes meaning.
- [ ] Results reported include failures and exclusions as described in methods.

## Disclosures
- [ ] Conflicts of interest declared. [ ] Funding acknowledged.
- [ ] Ethics approval (if human subjects, personal data, or road tests on public roads require it per institution).
- [ ] AI-use statement per the venue's verified policy, describing actual use.

## Citations
- [ ] Every reference verified to exist and to support the cited statement.
- [ ] No excessive or coerced self-citation; no citation of retracted work without noting it.
