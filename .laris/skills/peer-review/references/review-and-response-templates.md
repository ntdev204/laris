# Review and response templates

## Referee report (mode a)
1. Summary (3-5 sentences, own words): problem, approach, main claims, evidence.
2. Overall assessment: significance, novelty, soundness, clarity (one short paragraph each).
3. Major comments (numbered): location, issue, why it matters, what would resolve it.
4. Minor comments (numbered): presentation, typos, notation, figures.
5. Recommendation: accept / minor revision / major revision / reject, consistent with comments.
6. Confidential comments to the editor: concerns not suitable for authors (e.g., suspected overlap), stated factually.

## Revision plan (mode b)
| ID | Comment (short) | Type | Decision | Action | Location | Needs (analysis/ref) | Owner | Status |

## Response letter entry
**Reviewer 1, Comment 1.** > [verbatim comment]
**Response.** We thank the reviewer ... [agree / partially agree / respectfully disagree, with reason].
**Action.** [What changed] (Section X, p. Y, lines Z). [New text if short.]
**Evidence.** [Data, derivation, or verified reference, for rebuttals or partial acceptance.]

## Tone rules
Courteous and specific; no flattery padding; never "the reviewer is wrong", instead explain with evidence;
acknowledge good points plainly.
