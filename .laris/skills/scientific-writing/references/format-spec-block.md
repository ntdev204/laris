# Format spec block

Fill every field; write "unverified" or "not specified" rather than guessing. Cite the source of each rule.

```text
FORMAT SPEC BLOCK  (date: YYYY-MM-DD)
Venue / recipient:        e.g., IEEE Transactions on Intelligent Transportation Systems | advisor
Source of rules:          URL of official author guidelines / supplied template file / "temporary default"
Paper / document type:    regular paper | letter | conference paper | thesis chapter | report | outline | cover letter | response letter
Language and spelling:    English (US) | English (UK) | Vietnamese
Required sections/order:  ...
Limits:                   pages ...; words ...; abstract ... words; figures/tables ...; keywords ...
Citation style:           IEEE numeric | APA author-year | Vancouver | ... ; file: IEEEtran.bst | apa.csl | biblatex style=...
Math conventions:         equation numbering ...; theorem/assumption environments ...; units SI
Figures/tables:           width (single/double column), font size, color policy, file formats
Submission form:          LaTeX class ... | Word template ...; double-blind yes/no; cover letter yes/no;
                          author contributions / data availability / AI-use statement required?
Output route:             docx (docx skill) | LaTeX (.tex + .bib) | docs (collaborative, on request)
Open questions:           anything not verified
```

## Neutral IMRaD temporary default (only when nothing is given and the user cannot answer)
Title, Abstract, Keywords, 1 Introduction, 2 Related Work, 3 Problem Formulation / Methods,
4 Results, 5 Discussion (incl. limitations), 6 Conclusion, References. Mark it "TEMPORARY DEFAULT".

## When the venue changes
List: class/template, page/word limits, abstract limit, section order, citation style, anonymization,
required statements, figure specs. Get confirmation, then edit.
