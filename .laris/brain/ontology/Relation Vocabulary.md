# Relation Vocabulary

The typed links between notes and graph edges: requires, uses, feeds, contrasts, validates.


requires: needed before this note can be applied. uses: applies another note during its procedure. feeds: its output is input to another note. contrasts: differs from or limits another note. validates: provides a test or measure for another note. Add a new type only by owner decision.
