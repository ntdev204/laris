# Inclusion Criteria

Write the inclusion rule before looking at results: population, time window, language, document type.


State the rule in one sentence and record it in the answer. Apply it to every document the same way. Report how many documents the rule excluded and why. Changing the rule after seeing results is a new analysis, not an adjustment.
