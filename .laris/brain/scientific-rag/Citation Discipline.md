# Citation Discipline

Cite every claim as [source #rank]; a citation must support the sentence it follows.


Use the source and rank returned by the search tool. Do not cite a source that was not retrieved. One citation per claim is enough; stacking citations hides which one supports it. If a claim needs two sources, name both.
