# Relation Typing

Give each relation a type from the vocabulary and a direction; unknown relations stay generic and are flagged.


Choose the narrowest type the passage supports. Record direction. A generic related-to edge is allowed only as a placeholder and is excluded from path answers. Hedged statements keep their hedge as an edge property.
