# Tool Map

Pick the smallest tool that does the job: status, search, read, extract, write only after approval.


corpus_status checks size first. search_corpus finds passages. read_file reads a given file. extract_discourse structures text. answer_question gives an extractive answer when a model is available. ingest_path and write_file change state and need approval. Brain tools navigate internal guidance and never serve as evidence.
